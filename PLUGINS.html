01

Core Framework

The plumbing everything else runs on. No interaction — they just work in the background.

lazy.nvim

folke/lazy.nvim

The plugin manager itself. Installs, lazy-loads (only starts a plugin once its command/keymap/filetype/event actually fires), and updates every plugin in this document. Open it with :Lazy.

LazyVim

LazyVim/LazyVim

The starter-kit distribution this whole config is built on top of. Ships sane default options, keymaps, and a curated plugin set — every file in lua/plugins/ overrides or extends it.

plenary.nvim

nvim-lua/plenary.nvim

A shared Lua standard library — async jobs, path handling, test helpers — that dozens of other plugins depend on internally. You never call it directly.

nui.nvim

MunifTanjim/nui.nvim

A UI component toolkit (popups, inputs, menus, layouts) that noice.nvim and others use internally to draw their floating windows.

Custom Plugin — lutos.nvim

Your own plugin, inspired by VS Code's "Peacock" extension.

lutos.nvim

sfn101/lutos.nvim

What it does: paints a colored vertical bar down the left edge of the editor window so you can tell different projects/workspaces apart at a glance when several Neovim windows or tmux panes are open side by side. Example: color your api repo blue and your frontend repo green, so a stray keystroke in the wrong window is obvious before you even read the file path.

How it works: a hybrid renderer — it wraps your existing statuscolumn for the buffer content area (so diagnostics/git/fold signs stay untouched), plus a shared floating window for empty space below the last line, so the bar always covers the full window height. The chosen color is saved per-directory in ~/.local/share/nvim/lutos_state.json and restored automatically next time you open that project.

  • 18 preset colors, including VS Code Peacock's framework-branded picks ("React Blue", "Vue Green")
  • Per-workspace persistence — set once, remembered forever for that directory
  • Updates live as you scroll, resize, or edit
  • Doesn't interfere with existing sign-column content
KeyAction
<leader>wpOpen the color picker to paint the current workspace default
